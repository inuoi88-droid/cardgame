# 公式カード「黎明の大陸」（ドラフト戦の山）

オンラインのドラフト戦（決定事項 #116）で使うカードの山。CPU 戦のドラフト（#/battle/draft）でも、初期設定はこの山を使う。
実装は `src/official/`（`cards.ts` が中身、`index.ts` が窓口）。純粋なデータと関数だけで、UI・CPU・サーバー（Edge Function）が同じものを読む。

- **120種類**：コモン72・レア32・エピック16。**レジェンドは入れない**（ドラフトでは出さない）
- ID は `official-<slug>`（変えない）。カードの中身を変えたら `OFFICIAL_SET.version` を上げる
- 数値はプリセットと同じく倍率1で書き、`fromBaseScale` で今の倍率（20）にする。下の表の数字はゲーム内の数字（倍率20）
- どのカードもカード作成のルールを守り、予算（レアリティ上限）をほぼ使い切っている（残りは上限の3割以内。`tests/official.test.ts`）
- 絵は game-icons.net（`gi:<名前>`。同じ絵は使い回さない）、説明（フレーバー）はほぼ全部のカードにある（80文字以内）

## ドラフトとの関係

- 場に6枚、交互に1枚ずつ取り、取ったら山から1枚補充。1回で同じカードが2枚入り、15回ずつで30枚のデッキになる
- レアはデッキに8枚まで・エピックは4枚までなので、**1人が取れるのはレア4回・エピック2回まで**。残りの9回以上はコモンになる。だからコモンだけでデッキの骨格が組めるように作った（どの色もコモン12種類に、序盤のモンスター・除去・中盤・重いカードがある）
- 伏せた山はコモン2枚ずつ・レアとエピック1枚ずつの192枚（`BALANCE.draft.pileCopies`。#117）。同じコモンが場に2枚並ぶこともある。1回のドラフトで見るのは40枚前後で、そのうちレアは約6枚・エピックは約3枚（1種類1枚ずつの山だとレア約10枚・エピック約5枚で、2人の上限とほぼ同じになり、レアリティが珍しさにならなかった）
- 色をそろえるのは運しだいなので、汎用のカード（除去・効率のよいモンスター）を多めにして、2色や3色の混ざったデッキでも戦えるようにした

### 作り方の決まり

- **コモンは読みやすく**：効果は3つまで（ほとんど1〜2つ）、条件は1つまで、カードの能力・モード選択なし
- **レア・エピックは仕組みを少し足す**：モード選択（旅人の選択）・カードの能力（サイクリング・起動）・種族の全体強化・倍化など。テキストは2〜3行に収める
- **手札は毎ターン捨てる**ルールなので、カードを引くだけ・回収するだけのカードは弱い。どのカードも盤面か相手の HP に触れる効果を持たせた
- **呪いカード**（デメリットのあるカード）はデメリットの合計がレアリティ上限以上で、上限まで予算が増える（#64）。血の契約の自傷は差し引ける上限ちょうど（コモンで倍率1の4）にした（上限を超えた分はただの損になるため。#117）。手札は毎ターン全部捨てるので、デメリット「手札喪失」は最後に使えば払わずに済む。だから使わない
- CPU が扱いにくい・オンラインで偏りやすいもの（無限の繰り返し、追加ターン、コモンの大きなカード・アドバンテージ、全体を永続で大きく強化するコモン）は入れない。全体強化はエピック「群れの大号令」とレア「歯車の指揮官」だけで、どちらも量を抑えた

## 測定（版1。CPU ふつう。`node scripts/sim/official.mts`）

レビューを受けて直したあと（#117。山はコモン2枚ずつ）：

- **ドラフト**（`draft 300 2`。エンジンの createDraft で、簡単な取り方）：主なアーキタイプごとの勝率 血の契約 53.7%・歯車工房 52.7%・白銀の砦 52.1%・毒沼 49.6%・牙の群れ 42.7%。先に取った側の勝率 48.7%。試合の長さの中央値 13ターン（p90 16）。カードごとの勝率は 34〜72%（上位は白銀の巨像 71.8%・聖光の波 70.0%・死毒の宣告 66.3%、下位は毒蛇の巫女 34.4%・老練の騎士 36.6%・嵐の鷲 37.0%）。レアリティごとの平均はコモン 49.5%・レア 51.4%・エピック 52.0%（直す前とほぼ同じ。コストの差し引きに比べて上限の差が小さい仕組みのため）
- **取り方どうし**（`pickers 40 2`、各80試合）：おまかせ（つよい）対 でたらめ 67.5%・対 よわい 58.8%・対 簡単な取り方 62.5%。燃やしだけ 対 おまかせ（ふつう）37.5%、汎用だけ 対 おまかせ（ふつう）41.3%（どちらも55%を超えないので、汎用の除去は色に移していない）。おまかせの強さの目安を「コストで引く前のポイント」から「差し引き後のポイント」に替えたら、替える前のおまかせ（つよい）に 65.6%（160試合）
- **コモンだけのデッキ**（`common 40`）：歯車工房 67.0%・血の契約 60.5%・白銀の砦 52.5%・汎用 50.5%・牙の群れ 49.5%・毒沼 20.0%。「弱り目の一刺し」をレアにしたので、コモンだけの毒沼は決め手が足りない（毒塗りの短剣に「毒状態なら100ダメージ」を付けても 12.5%→20.0%）。ドラフトの毒沼は 49.6% なので、ドラフトの数字を優先した
- 直す前（#116）：ドラフト 白銀の砦 58.7%・血の契約 50.9%・牙の群れ 50.7%・歯車工房 46.2%・毒沼 44.3%、先に取った側 52.4%、コモンだけ 毒沼 72.3%〜牙の群れ 37.7%
- どの数字も1組み合わせあたりの試合数が少ない（±5〜7pt の誤差）。オンラインの結果で測り直す

## バランス（ドラフト戦の本番の形での測定。決定事項 #118・版2）

`npm run sim:draft`（`scripts/sim/draft.mts`）で、オンラインと同じ形のドラフトを CPU どうしで回して測った。公式カードの山・場に6枚・交互に15回ずつ（エンジンの `createDraft`・`applyTake`）、1戦目は後から取り始めた人が先攻、2戦目は「同じデッキでもう一戦」（前の負けが先攻）。席ごとの取り方は、本物のおまかせ（よわい・ふつう・つよい）と、色をそろえる取り方（focus・ばらつきの大きい focus-wide）をシードで混ぜた。

測った条件（直す前と直した後で同じシード）：`node scripts/sim/draft.mts 1600 2 --hard 600 --lethal 30 --swap 400 --seed 20000`
＝ドラフト1600回×2試合（CPU ふつう）、つよいどうし600回×1試合、席の入れ替え400回（同じデッキ・同じシードで先攻だけ入れ替えて2試合）、リーサル検査30回。

### 残っていること

- **牙の群れはつよいどうしで弱い**（38.8%、±8pt。ふつうでは 48.7%）。速攻と小さい体の獣は、反撃のある戦闘でつよいの CPU に受け止められやすい。1段階（体力20）の調整が予算の幅（3割）を超えるカードが多く、細かく直せない。オンラインの結果で測り直す
- **勝率の高いカード**：白銀の巨像 66%（攻撃力・体力・守備力の組み方を3通り試しても 66〜69% から動かない。挑発で攻撃を受け止め続けること自体が強いのかもしれない）、毒の決め手（死毒の宣告・弱り目の一刺し 62〜63%。毒沼の勝ち筋そのもので、毒沼全体は 49.6%）。カードごとの勝率は入っていたデッキの勝率なので、強い人がよく取るカードほど高く出る
- 先に取った人の1戦目の勝率（55.8%）と、先攻の決め方（上の「先攻」）
- CPU のリーサルの見逃し（27手番で2回）。カードではなく CPU の探索の問題（プリセットの実戦でも 6手番で1回）
