# 依頼

> **注記：本文は最初の原案。食い違うときは末尾の決定事項ログが優先する。** 明らかに変わった箇所には〔→ 決定事項 #番号〕の形で注記を添えている（原文はそのまま残す）。

全カードをプレイヤーが自作して戦う、1対1のオンライン対戦カードゲーム（タイトル未定）を作ってください。カードはポイント制で作成し、ステータスと効果を組み合わせて自由にカスタマイズします。対戦の感覚はSlay the Spireに近く、オンライン対戦をメインに、CPU戦も用意します。

# 進め方

1. まずこの依頼文の仕様を docs/SPEC.md にそのまま保存し、開発ルールの要約を CLAUDE.md に書いてください。
2. 下の3フェーズを順番に進めます。各フェーズの最初に実装計画（ファイル構成、データ構造、作業手順）を示して私の承認を得てから着手してください。フェーズの終わりにはテストを通し、私が動作確認する手順を示して止まってください。
3. ゲーム性に影響する判断（ルール、数値、効果の挙動）で仕様に書かれていないものは、推測で決めずに質問してください。実装上の細かい判断は自分で決め、docs/SPEC.md の末尾に「決定事項ログ」として記録してください。
4. 数値はすべて仮で、テストプレイで調整します。バランスに関わる数値は src/engine/balance.ts の1か所にまとめ、コード内に直接書かないでください。
5. 作業のまとまりごとにgitでコミットしてください。

# 技術方針

- TypeScript + Vite + React。UIは日本語で、スマホでも遊べるレイアウトにする
- ルールエンジン（ポイント計算、カード判定、対戦処理）はUIから完全に分離した純粋関数で書く。対戦処理は「状態とアクションを受け取り、新しい状態を返す」形にし、乱数はシード付きにする。同じエンジンをCPU戦とオンライン対戦のサーバー側でも使う
- 効果は、定義データと処理関数を1か所に登録するレジストリ方式にする。新しい効果を1ファイル追加すれば、エディター、ポイント計算、効果テキスト、対戦処理のすべてに反映される構成にする
- テストはVitest。下の「作成例」4枚の計算結果をテストケースにし、ルール違反で作成できないケースのテストも加える

カードデータの形（参考。改善してよい）
{
  id, name, icon, rarity, cost,
  stats: { attack, hp, defense } または null,
  keywords: [{ id, value }],
  effects: [{ id, value, hits, timing, target, condition }],
  drawbacks: [{ id, value, timing }]
}
カードの種類、呪い判定、ポイント、効果テキストは保存せず、毎回エンジンで計算する。

# Phase 1：カードエディターとデッキ構築

カードエディター
- 入力項目：カード名、アイコン（絵文字から選択）、レアリティ、コスト、モンスターのステータス、キーワード、効果、デメリット
- 効果ごとに、数値、発動タイミング、対象、条件を選べる。選べる組み合わせはカードの種類に応じて絞る
- 入力に合わせて、合計ポイント、内訳、上限までの残りをリアルタイムで表示する。上限超過やルール違反は理由を赤字で表示し、保存できないようにする
- カードの種類と呪い判定は自動で決め、効果テキストも自動生成する（例：攻撃するたび、相手に毒1を与える。）
- カード風のプレビューを表示する。枠の色はレアリティごとに変え、呪いカードは専用の見た目にする

保存とデッキ構築
- カードとデッキは localStorage に保存し、JSONでエクスポートとインポートができるようにする
- デッキは30枚。レアリティごとの枚数制限を満たさないと保存できない

# Phase 2：対戦エンジンとCPU戦

- 下の「対戦ルール」をすべて実装する
- CPUは、使えるカードを評価値の高い順に使う簡単なAIから始め、後で強くできる構造にする
- CPU用のプリセットデッキを3つ作る（毒中心、モンスター中心、呪いカード中心）。すべてポイントルールを守ること
- 対戦画面に、両者のHP、シールド、状態異常、場のモンスター、手札、エナジー、山札と捨て札の枚数、対戦ログを表示する
- 効果の発動順やダメージの計算過程がわかるよう、ログは細かめに出す

# Phase 3：オンライン対戦

- 通信にはSupabaseを使う。既存のプロジェクト（ability-debate、他アプリと共用中）を使うか新規に作るか、公開方法（GitHub Pages、Vercel、Googleサイトへの埋め込みの有無）は、Phase 3 の開始時に私に確認すること
- 不正防止のため判定はサーバー側で行う。アクションはEdge Functionで受け取り、Phase 2 と同じエンジンで検証して適用する
- 相手の手札や山札の順番がクライアントに届かない設計にする。完全な状態はサーバーだけが持ち、各プレイヤーには相手の非公開情報を隠した状態だけを配信する
- ルームコードを使って対戦相手と同じ部屋に入る。対戦開始時に、サーバー側でデッキの合法性を検証する
- 1ターンの制限時間（仮に90秒）と、切断時の再接続に対応する

# 対戦ルール（仮）

基本
- プレイヤーのHPは60。毎ターン、エナジー3を得て5枚引く 〔→ #69：HP は 120（倍率1の数字。実際は倍率を掛ける）。エナジーは自分のターン数で成長し、1〜3ターン目 3、4〜6ターン目 4、7ターン目以降 5。#47：1ターン目は対戦開始時に配った5枚（マリガンあり）〕
- ターン終了時の効果を処理した後、手札をすべて捨て札にする
- 山札が尽きたら、捨て札をシャッフルして山札にする
- 先攻は1ターン目のエナジーが2 〔→ #69：基本値から −1（3−1＝2）。#73：後攻の1ターン目は基本値に +1（3+1＝4）〕
- 相手のHPを0にしたら勝ち。30ターン経過で引き分け 〔→ #26：各プレイヤー30ターンずつ。後攻の30ターン目が終わって決着していなければ引き分け〕

カードの使い方
- アタックとスキルは、使用後に捨て札へ行く
- パワーは使用後にゲームから除外され、効果は試合中ずっと続く
- パワー・アタックは、ダメージを与えたうえで永続効果を残し、除外される
- モンスターは自分の場に召喚する（場は最大5体）。破壊されたら捨て札へ行く 〔→ #46：場のモンスターの数は無制限〕

モンスターの戦闘
- 召喚した次の自分のターンから、毎ターン1回攻撃できる
- 攻撃対象は、相手プレイヤーか相手モンスターから選ぶ
- ダメージは「攻撃力 − 相手モンスターの守備力」で、最低1。攻撃されたモンスターは反撃しない 〔→ #69：攻撃されたモンスターは反撃する。守備側がその時点の攻撃力を攻撃側に返し、攻撃とは同時に解決する（相打ちあり）。プレイヤーへの攻撃には反撃なし〕
- 守備力はモンスター専用。プレイヤーの防御手段はシールド

状態異常と持続効果（ターン数は付与された側のターンで数える）
- 毒：付与された側のターン開始時に、毒の数だけダメージを受け、その後1減る。守備力とシールドを無視する 〔→ #69：「1減る」ではなく半分（切り捨て）になる。再生も同じ〕
- やけど：3ターンの間、付与された側のターン終了時に2ダメージ。その間の回復量は半分（切り捨て）。重ねがけで残りターン+1 〔→ #36：重ねると新しいやけどのターン数（3＋延長）をまるごと足す。#68：延長の上限は5ターン〕
- 凍結：付与された側の次のターン、モンスターは攻撃できない。プレイヤーは最初に使うカードのコスト+1
- 弱体：与えるダメージ−25%（切り捨て）
- 脆弱：受けるダメージ+50%（切り捨て）
- 出血：攻撃を受けるたびに、出血の値だけ追加ダメージ。付与された側のターン終了時に半分（切り捨て）
- 封印：モンスターの効果とキーワードをすべて失わせる
- 混乱：次のターン、モンスターの攻撃対象がランダムになる
- シールド：受けるダメージを先に肩代わりする。次の自分のターン開始時に消える
- 反撃：次の自分のターン開始時までに攻撃を受けたら、攻撃してきた相手にダメージを返す 〔→ #32・#70：プレイヤーにかかる状態。1枚のカードの使用・1回のモンスターの攻撃につき1回だけ返す。モンスター同士の攻撃で守備側が返す「反撃」（#69）とは別物〕

# カード作成ルール

ポイント計算
- ステータス、効果、キーワードのポイントの合計から、コスト×10とデメリットのポイントを引く。その値がレアリティの上限以下なら、そのカードを作れる 〔→ #67：コストの差し引きは「コスト×10」ではなく表 0／10／20／32／45／58。コスト0はレアリティ上限が2下がる。#64：デメリットで差し引けるのはレアリティ上限まで、コスト0はデメリットで差し引けない。#65〜#67：実際の数字はすべて倍率 SCALE（20）を掛けたもの〕
- 効果1つのポイントは「基礎ポイント × タイミング倍率 × 対象倍率 × 条件倍率」。効果ごとに小数点以下を切り上げる
- デメリットにも同じ倍率を掛け、小数点以下を切り捨てる

レアリティ
- コモン：上限5pt。枚数制限なし
- レア：上限8pt。デッキに計16枚まで、同名カードは5枚まで 〔→ #67：計8枚まで、同名3枚まで〕
- エピック：上限12pt。計8枚まで、同名カードは3枚まで 〔→ #67：計4枚まで、同名2枚まで〕
- レジェンド：上限18pt。計4枚まで、同名カードは1枚まで 〔→ #67：計2枚まで、同名1枚まで〕

呪いカード
- デメリットを1つでも付けたカードは、自動的に呪いカードになる。元のレアリティ（コモンからレジェンド）はそのまま残る
- 呪いカードには枚数制限がない 〔→ #64：呪いカードも元のレアリティの枚数制限に従う〕
- その代わり、デメリットのポイントの合計が、そのレアリティの上限以上でなければ作れない
- 同じデメリットは1枚に1回まで

カードの種類の自動判定（上から順に判定する）
1. ステータスがある：モンスター
2. プレイヤーに永続的に残る効果（パワー用タイミングの効果、筋力）と、相手へのダメージ効果の両方がある：パワー・アタック
3. プレイヤーに永続的に残る効果がある：パワー
4. 相手へのダメージ効果がある：アタック
5. それ以外：スキル

安全装置
- 効果は1枚につき3つまで（コモンは2つまで）。キーワードとデメリットは数に含めない 〔→ #66：コモン3つ・レア以上4つまで〕
- 守備力の上限は3
- 1ターンに引けるのは合計10枚まで、増やせるエナジーは合計+3まで 〔→ #64：そのまま有効（#44 で一度外したが戻した）〕
- 条件は1つの効果につき1つまで
- カードを使うたびに発動する効果は、1ターン3回まで 〔→ #70：パワー1つにつき1ターン2回まで。ほかの安全装置（ダメージ合計30まで・連撃2〜5回・毒1〜10・筋力の合計10まで・妨害の上限）は #64・#70〕

# ステータス

- モンスターの攻撃力 +1：3pt
- 体力 +1：2pt
- 守備力 +1：4pt
- コスト +1：−10pt 〔→ #67：コスト表 0／10／20／32／45／58〕

# 効果一覧（基礎ポイント）

〔→ #68：以下の基礎ポイントは原案。現在の価格表（効果・キーワード・デメリット・タイミング／対象／条件の倍率）は決定事項 #68 の「旧→新」一覧と `src/engine/balance.ts` が正。主な変更：防御無視・吸収 +40%、処刑 2N、回復 2N、無効化 10、封印 8、混乱 4、弱体 5N・脆弱 7N（N≤3）、出血 6N、ドロー 4N、エナジー 8N、ドロー妨害 5、エナジー妨害 12、バウンス 8+4N（コストN以下のモンスターを戻す）、奪取 45、飛行 3、貫通 max(2, 0.5A)、二回攻撃 4A、隠密 2+A、不屈 3+A など〕

ダメージ系
- ダメージ：N点ダメージ／2pt×N
- 連撃：N点ダメージをM回（守備力で毎回軽減される）／2pt×N×M
- 防御無視：付けたダメージ効果が守備力とシールドを無視する／そのダメージ効果のポイントの+50%
- 吸収：与えたダメージの半分（切り捨て）だけ回復する／そのダメージ効果のポイントの+50%
- 処刑：体力N以下の相手モンスターを破壊／3pt×N
- 反撃：攻撃してきた相手にN点ダメージを返す／1.5pt×N

防御・回復系
- シールド：N点／1.5pt×N
- 回復：自分のHPをN回復／3pt×N
- 無効化：次に受けるダメージ1回を0にする／15pt
- 浄化：自分の状態異常をすべて解除／6pt
- 修理：自分のモンスター1体の体力をN回復（最大値まで）／1pt×N

状態異常（相手に付与）
- 毒N／3pt×N
- やけど／10pt（延長1ターンごとに+3pt）
- 凍結／12pt
- 弱体（Nターン）／4pt×N
- 脆弱（Nターン）／5pt×N
- 出血N／3pt×N
- 封印／15pt
- 混乱／8pt

強化系
- 筋力：以後ずっと、自分のアタックのダメージ+N／8pt×N
- 気合：このターンだけ、アタックのダメージ+N／2pt×N
- 攻撃力アップ：自分のモンスター1体の攻撃力+N（永続）／3pt×N
- 守備力アップ：自分のモンスター1体の守備力+N（永続）／4pt×N
- 再生：ターン開始時にN回復し、その後Nが1減る／4pt×N

リソース系
- ドロー：N枚引く／5pt×N
- エナジー：このターンのエナジー+N／9pt×N
- 貯金：次のターンのエナジー+N／7pt×N
- 軽減：次に使うカードのコスト−1／7pt
- サーチ：山札から、作成時に指定した種類のカードを1枚選んで手札に加える／8pt
- 回収：捨て札から1枚を選んで手札に加える／8pt
- 保持：ターン終了時に手札を1枚残せる／4pt

妨害系
- ドロー妨害：相手が次のターンに引く枚数−1／10pt
- エナジー妨害：相手の次のターンのエナジー−1／15pt
- ノイズ投入：相手の山札に「ノイズ」をN枚混ぜる。ノイズは効果のないカードで、コスト1を払えば除外できる／4pt×N
- バウンス：相手モンスター1体を持ち主の手札に戻す／12pt 〔→ #68・#70：「コストN以下の相手モンスター1体を持ち主の手札に戻す」8pt＋4pt×N。コストが上なら不発〕
- 弱化：相手モンスター1体の攻撃力−N（永続、最低0）／3pt×N
- 解除：相手の永続効果を1つ消す／12pt

モンスター専用キーワード
- 速攻：召喚したターンから攻撃できる／攻撃力×2pt
- 挑発：このモンスターがいる限り、相手のモンスターはこのモンスターしか攻撃できない。アタックカードの対象には影響しない／8pt（→ #83 で変更：カードの効果の「選んだ1体」も挑発しか選べない）
- 飛行：挑発を無視して攻撃できる／6pt
- 貫通：モンスターを倒して余ったダメージが、相手プレイヤーに通る／5pt
- 二回攻撃：毎ターン2回攻撃できる／攻撃力×3pt
- 隠密：召喚してから、相手の次のターン終了まで攻撃対象にならない／5pt
- 不屈：一度だけ、体力1で踏みとどまる／8pt
- 自己修復：自分のターン開始時に体力をN回復／3pt×N

レアリティ限定の効果
- 蘇生（エピック以上）：捨て札にあるコストN以下のモンスターを場に戻す／10pt＋5pt×N
- 複製（エピック以上）：手札のカード1枚のコピーを手札に加える／12pt
- 全体破壊（レジェンドのみ）：自分の分も含め、場のモンスターをすべて破壊する／25pt
- 奪取（レジェンドのみ）：相手モンスター1体を自分の場に移す／35pt

# 倍率

〔→ #68：タイミング・対象・条件の倍率は改定済み（攻撃するたび 2.0×攻撃回数＋速攻なら1.0、パワーのターン開始時／終了時 4.0／4.5、カードを使うたび 8.0、条件は3段階から条件ごとの値、など）。詳細は決定事項 #68〕

発動タイミング
- 使用時、召喚時：×1.0（すべてのカード）
- 破壊されたとき：×0.8（モンスター）
- ダメージを受けたとき：×1.5（モンスター）
- 攻撃するたび：×2.0（モンスター）
- 毎ターン開始時または終了時：×2.5（モンスター）、×3.0（パワー）
- カードを使うたび：×4.0（パワー）

対象
- 選んだ1体（プレイヤーかモンスター）：×1.0
- ランダムな1体：×0.7
- 相手モンスター全体：×1.5
- 相手全体（プレイヤーとモンスターすべて）：×2.0
- 敵味方すべて：×1.2

条件（満たしていないときは効果が発動しない）
- ゆるい（×0.8）：自分の場にモンスターがいる、相手のHPが自分より多い
- ふつう（×0.6）：相手が毒状態、自分のHPが半分以下、手札が3枚以下
- きびしい（×0.4）：相手が毒とやけどの両方、このターン3枚目以降に使う、自分の場にモンスターが3体以上

# デメリット（呪いカード用。マイナスのポイント）

- 自傷：自分にNダメージ／−1.5pt×N
- 自毒：自分に毒N／−2pt×N
- 自分にやけど：自分がやけど状態になる／−7pt
- 手札喪失：自分の手札をランダムに1枚捨てる／−5pt
- 反動：次のターンのエナジー−1／−10pt
- 汚染：自分の山札にノイズをN枚入れる／−3pt×N
- 施し：相手が次のターンに1枚多く引く／−4pt
- 維持費（モンスター）：自分のターン開始時に自分に1ダメージ／−4pt（倍率込みの固定値）
- 寄生：手札にある間、ターン終了時に自分に2ダメージ／−5pt（倍率込みの固定値） 〔→ #70：「このカードを引いたとき、自分に N ダメージ」に変更。対戦開始時の手札とマリガンでも働く〕
- 裏切り（モンスター）：召喚から3ターン後、自分のプレイヤーを攻撃するようになる／−12pt（倍率込みの固定値） 〔→ #68：−(6＋3×攻撃力)pt〕

# 作成例（テストケース。計算結果が一致すること）
