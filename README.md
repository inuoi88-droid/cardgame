# 自作カードバトル

全カードをプレイヤーが自作して戦う、1対1の対戦カードゲーム。仕様は [docs/SPEC.md](docs/SPEC.md)。

## ブラウザで遊ぶ

https://cardgame-swart.vercel.app （スマホでもPCでも。オンライン対戦の相手にはこの URL を送ってください）

## PCで遊ぶ（インストール不要）

1. [`release/cardgame.html`](release/cardgame.html) をダウンロードします（GitHub ではファイルを開いて「Download raw file」ボタン）。
2. ダウンロードしたファイルをダブルクリックすると、ブラウザ（Chrome / Edge / Firefox / Safari）で開きます。

- カード作りと CPU 戦は、インターネットにつながっていなくても動きます。作ったカードはどこにも公開されません（オンライン対戦で使ったデッキだけ、対戦のためにサーバーへ送ります）。
- 作ったカードとデッキは、そのブラウザの中に保存されます。別のブラウザや別のPCでは見えないので、移すときや控えを取るときは「書き出し」→「取り込み」を使ってください。
- 新しい版の `cardgame.html` に置き換えても、同じブラウザで開けば保存したカードはそのまま使えます。
- 「🤖 CPU戦」から CPU と対戦できます（自分のデッキか、プリセットデッキを選べます）。対戦の途中で閉じても、次に開いたとき続きから再開できます。
- 「🌐 オンライン」から、ほかの人と対戦できます（インターネットが必要）。

## オンライン対戦の遊び方

1. 「🌐 オンライン」で名前とデッキを選び、1人が「部屋を作る」を押します。6文字の部屋コードが出ます。
2. もう1人は同じ画面で「コードで入る」にそのコードを入れて「入る」を押します。対戦が始まります。
3. 1ターンの制限時間は90秒です。時間切れになると自動でターンが終わり、3回続けて時間切れになると負けです。
4. 途中で閉じても、同じブラウザで開き直せば続きに戻れます（その間も時間は進みます）。

## 対戦のおもなルール

- 両者の HP は 2400（相手の HP を 0 にしたら勝ち。各プレイヤー30ターンで決着しなければ引き分け）。
- 毎ターンのエナジーは、自分の1〜3ターン目は 3、4〜6ターン目は 4、7ターン目以降は 5（先攻の1ターン目だけ 2、後攻の1ターン目だけ 4）。毎ターン5枚引き、ターン終了時に手札を捨てます。
- モンスターで相手のモンスターを攻撃すると、攻撃されたモンスターはその攻撃力ぶんのダメージを返します（反撃。同時に解決するので相打ちになることもあります）。相手プレイヤーへの攻撃には反撃はありません。
- 毒と再生は、効いたあと毎ターン半分になります。
- パワー（「ターン開始時」「カードを使うたび」などの効果が場に残るカード）は1人3つまで。4つ目を使うと、いちばん古いパワーが消えます（消えるときに効果は発動しません）。
- 挑発のモンスターが相手の場にいる間は、モンスターの攻撃も、カードの効果で「選んだ1体」も、挑発のモンスターしか選べません（相手プレイヤーも選べません）。飛行は攻撃のときだけ挑発を無視できます。ランダムや全体の効果、隠密中の挑発には関係ありません。
- MTG の要素カタログから採用した仕組み（決定事項 #85・#86）：
  - キーワード：接死・先制攻撃・呪禁・絆魂・武士道・聖盾
  - 効果：トークン生成（小鬼。1人5体まで、場を離れると消える）・鍛錬・衰弱・キーワード付与・格闘・再行動・占術・手札整理・処分・倍化・呪縛（毎ターン減らないダメージ）・一時強化
  - デメリット：防衛・寿命・腐乱・廃棄・生け贄
  - タイミング：自分のモンスターが出るたび・自分の他のモンスターが破壊されるたび・自分がパワー／スキルを使うたび・相手プレイヤーにダメージを与えたとき（「〜するたび」は1枚につき1ターン2回まで）
  - 条件：このターン相手にダメージを与えた・このターンにモンスターが破壊された・コイン投げ・後攻・手札が0枚 など12個
  - 対象：このモンスター・自分のモンスター全体・出たモンスター。数値の倍数：X（残りのエナジーをすべて使う）・相手モンスター1体につき・このターン使ったカード1枚につき
- 画面の「📖 ルール」に、遊び方とルールの説明があります。細かいルールと変更の経緯は [docs/SPEC.md](docs/SPEC.md) の決定事項ログにあります。

## 遊び方の流れ

1. 「🃏 カード」でカードを作ります（「テンプレートから作る」で雛形を読み込むと簡単です。「サンプルを追加」で見本のカードも入ります）。予算メーターを見ながら効果を足し、保存します。
   - 効果のタイミング・対象・条件は、押すと出る選択パネルで選びます（検索できます。見出しごとにまとまり、1行の説明と、選んだときのポイントが出ます。選べないものは理由つき）。
   - 「説明（任意）」に80文字までの説明を書けます（カードの下に小さく出ます。ルールには影響しません）。
   - 一覧でカードを押すと詳細（ポイントの内訳・使っているデッキ）が開き、編集・複製・削除ができます。
2. 「📚 デッキ」で作ったカードからデッキを組みます。自分のデッキがなくても、プリセットデッキ5つ（毒・モンスター・呪い・守り・コンボ）で遊べます。
3. 「🤖 CPU戦」でデッキと CPU の強さ（よわい／ふつう／つよい）を選んで対戦します。
   - よわい：読みが甘く、たまに損な手も打つ。ふつう：とどめを逃さず、1手ずつ一番よい手を選ぶ。つよい：ターン内の手順を先まで読む。
   - 対戦中は **ドラッグ＆ドロップ** で操作します。手札のカードを場へドラッグして離すと使えます（スマホは上へドラッグ。横になぞると手札のスクロール）。対象を選ぶカードは、カードから矢印が出るので、光っている対象（相手・モンスター）の上で離します。自分のモンスターを相手のモンスターかプレイヤーへドラッグすると攻撃です。使えないとき・選べない対象に落としたときは、カードが手札に戻って理由が出ます。手札に戻すか Esc で取り消し。
   - 対象を2つ選ぶカード（格闘など）は、片方に落としたあと、画面下の候補ボタンで残りを選びます。
   - カードやモンスターを押す（左クリック・タップ）と詳細が開きます（効果の全文・説明文・今の攻撃力や状態）。詳細の「使う」「攻撃する」からも操作できます（キーボードなら Tab で移動して Enter）。
   - ログのカード名は黄色で、押すと詳細が出ます。ダメージは赤、回復は緑です。相手の動きは順に再生されます（画面のどこかを押すと早送り）。
4. 「🌐 オンライン」で、ほかの人と対戦できます（下の「オンライン対戦の遊び方」）。

サーバーは Supabase（Edge Function「cardgame」と、専用スキーマ `cardgame` の表）です。勝敗の判定はすべてサーバーで行い、相手の手札や山札の中身はブラウザに送りません。

## 開発用の動かし方

Node.js 22.12 以上が必要です。

```
npm install
npm run dev
```

表示された URL（例：http://localhost:5173/）をブラウザで開きます。スマホで確認するときは `npm run dev -- --host` で起動し、同じ Wi-Fi のスマホから表示されたネットワーク側の URL を開きます。

## テスト

```
npm test
```

## 配布用ファイルの作り直し

```
npm run build:single
```

`release/cardgame.html`（JS と CSS を埋め込んだ HTML 1ファイル）が作り直されます。

## サーバー（オンライン対戦）の更新

1. `npm run build:server` で `supabase/functions/cardgame/engine.js`（`src/online` とエンジンをまとめた1ファイル）を作り直し、コミットして push します。
2. Edge Function「cardgame」をデプロイし直します（JWT の検証はオフ。本人確認は独自のトークンで行います）。
   Supabase CLI なら `supabase functions deploy cardgame --no-verify-jwt --project-ref hefydmrqrdumpifbqlfp`。
3. 表を変えるときは `supabase/migrations/` に SQL を足して適用します（ability-debate と共用のため、`cardgame` スキーマの外には触れません）。

公開は Vercel（チーム sochi のプロジェクト「cardgame」、設定は `vercel.json`）。GitHub のこのブランチに push すると自動で更新されます。
