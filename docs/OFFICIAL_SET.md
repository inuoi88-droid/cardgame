# 公式カード「黎明の大陸」（ドラフト戦の山）

オンラインのドラフト戦（決定事項 #116）で使うカードの山。CPU 戦のドラフト（#/battle/draft）でも、初期設定はこの山を使う。
実装は `src/official/`（`cards.ts` が中身、`index.ts` が窓口）。純粋なデータと関数だけで、UI・CPU・サーバー（Edge Function）が同じものを読む。

- **126種類**：コモン72・レア32・エピック16・レジェンド6（版3。各色と汎用に1枚。ドラフトの山に1枚ずつで、1人1枚まで：#134・#136）
- ID は `official-<slug>`（変えない）。カードの中身を変えたら `OFFICIAL_SET.version` を上げる
- 数値はプリセットと同じく倍率1で書き、`fromBaseScale` で今の倍率（20）にする。下の表の数字はゲーム内の数字（倍率20）
- どのカードもカード作成のルールを守り、予算（レアリティ上限）をほぼ使い切っている（残りは上限の3割以内。`tests/official.test.ts`）
- 絵は game-icons.net（`gi:<名前>`。同じ絵は使い回さない）、説明（フレーバー）はほぼ全部のカードにある（80文字以内）

## ドラフトとの関係

- 場に6枚、交互に1枚ずつ取り、取った場所に山から1枚補充し、さらに場にいちばん長く残っている2枚を山に戻して入れ替える（#134）。1回で同じカードが2枚入り（レジェンドは1枚）、15回ずつで30枚のデッキになる
- レアはデッキに8枚まで・エピックは4枚までなので、**1人が取れるのはレア4回・エピック2回まで**。残りの9回以上はコモンになる。だからコモンだけでデッキの骨格が組めるように作った（どの色もコモン12種類に、序盤のモンスター・除去・中盤・重いカードがある）
- 伏せた山はコモン2枚ずつ・レアとエピックとレジェンド1枚ずつの198枚（`BALANCE.draft.pileCopies`。#117・#134）。同じコモンが場に2枚並ぶこともある。1回のドラフトで見るのは40枚前後で、そのうちレアは約6枚・エピックは約3枚（1種類1枚ずつの山だとレア約10枚・エピック約5枚で、2人の上限とほぼ同じになり、レアリティが珍しさにならなかった）
- 色をそろえるのは運しだいなので、汎用のカード（除去・効率のよいモンスター）を多めにして、2色や3色の混ざったデッキでも戦えるようにした

### 作り方の決まり

- **コモンは読みやすく**：効果は3つまで（ほとんど1〜2つ）、条件は1つまで、モード選択なし。カードの能力は簡単なもの（キッカー・サイクリング・起動・親和）を1つまで（版3：#136）
- **コストは軽め**（版3：#136）：どの色もコモンの半分以上がコスト2以下、コモンにコスト5は無い
- **レア・エピックは仕組みを少し足す**：モード選択（旅人の選択）・カードの能力（サイクリング・起動）・種族の全体強化・倍化など。テキストは2〜3行に収める
- **手札は毎ターン捨てる**ルールなので、カードを引くだけ・回収するだけのカードは弱い。どのカードも盤面か相手の HP に触れる効果を持たせた
- **呪いカード**（デメリットのあるカード）はデメリットの合計がレアリティ上限以上で、上限まで予算が増える（#64）。血の契約の自傷は差し引ける上限ちょうど（コモンで倍率1の4）にした（上限を超えた分はただの損になるため。#117）。手札は毎ターン全部捨てるので、デメリット「手札喪失」は最後に使えば払わずに済む。だから使わない
- CPU が扱いにくい・オンラインで偏りやすいもの（無限の繰り返し、追加ターン、コモンの大きなカード・アドバンテージ、全体を永続で大きく強化するコモン）は入れない。全体強化はエピック「群れの大号令」とレア「歯車の指揮官」だけで、どちらも量を抑えた

### 残っていること

- **牙の群れはつよいどうしで弱い**（38.8%、±8pt。ふつうでは 48.7%）。速攻と小さい体の獣は、反撃のある戦闘でつよいの CPU に受け止められやすい。1段階（体力20）の調整が予算の幅（3割）を超えるカードが多く、細かく直せない。オンラインの結果で測り直す
- **勝率の高いカード**：白銀の巨像 66%（攻撃力・体力・守備力の組み方を3通り試しても 66〜69% から動かない。挑発で攻撃を受け止め続けること自体が強いのかもしれない）、毒の決め手（死毒の宣告・弱り目の一刺し 62〜63%。毒沼の勝ち筋そのもので、毒沼全体は 49.6%）。カードごとの勝率は入っていたデッキの勝率なので、強い人がよく取るカードほど高く出る
- 先に取った人の1戦目の勝率（55.8%）と、先攻の決め方（上の「先攻」）
- CPU のリーサルの見逃し（27手番で2回）。カードではなく CPU の探索の問題（プリセットの実戦でも 6手番で1回）

## 版3：単調なカードの作り直し・軽いコスト・レジェンド（決定事項 #136）

ユーザーの声「コストバランスが悪い（重いカードが多い）」「カード内容が単調」への対応。今のカードを1枚ずつ見て、ステータスだけ・効果1つだけのカード（`MONO` と印を付けた約75枚）を作り直した。毒・獣・呪い・守り・機械それぞれの勝ち筋（毒の回った相手・仲間の獣・HP を払う・挑発の壁・機械の数）に沿って、効果を1〜2つ足すか、仕組みのあるキーワード・能力に替えた。

- **新しく使った仕組み**：攻撃・破壊・ダメージを受けたとき・仲間が出る／倒れるたびの効果、「仲間の獣・機械がいれば」、占術、キッカー・サイクリング・起動・親和（コモンでも1つまで）、モード選択（レア）、トークン、武士道・猛襲・後援・対空・隠密・不屈・自己修復など
- **コスト**：コスト5のカードをなくし、3〜5の多くを1つ軽くした。平均コスト 2.17 → 2.06、コモンのコスト3は 8 → 5枚。どの色もコモンの半分以上がコスト2以下
- **レジェンド6枚**：毒沼の魔女王・百獣の祖霊・不死の王・白銀の聖女・歯車の大工匠・蒼海の覇竜。ドラフトの山に1枚ずつ（1人1枚まで、デッキには1枚）
- **予算は倍率1と実際の倍率の両方で確かめる**：ポイントの丸めが倍率で違い、片方で予算の3割以内でも、もう片方ではみ出すことがある（9枚が倍率1だけ上限を0.5〜1.5超えた）。数値を探すときは両方で通る組を選んだ

### 残っていること（版3）

- **牙の群れが少し弱い**（ふつう 41.9%、160試合・±8pt。版2でもいちばん下だった）。小さな獣は守備力・挑発の壁・反撃に止められやすく、1マナの獣（野犬の斥候・茂みの山猫・群れの若狼）が予算の上限にいて数値で上げにくい。オンラインの結果で測り直す
- **勝率の高いカード**：白銀の聖女（レジェンド）65.8%、鮮血の短剣 64.3%（84試合）、死毒の宣告 63.9%、鉄の大蜘蛛 62.8%。低いカード：縄張りの番獣 35.7%（126試合）、群れの大号令 40.6%
- **つよいどうしで先に取った人が 64%**（50試合・±14pt）。ふつうでは 51.5%
- **コモンだけの歯車工房が強い**（81%）。ドラフトでは 51.0% なので、色をそろえたコモンのデッキだけの強さ。ドラフトで機械のコモンばかり集まったときに目立つかもしれない
- CPU のリーサルの見逃し（19手番で4回）。カードではなく CPU の探索の問題
